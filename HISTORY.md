# OpenOLMS — Project History

## Timeline

### 1994 — Original Release
- v1.00.10, June 18, 1994 — initial program release
- v1.01.00, June 21, 1994 — trailing slashes, errorlevel fix, modem buffer clear

### 1994-1998 — Active Development
- Added JAM message base support, BlueWave offline mail
- Full-screen internal chat with word wrap
- Multi-language support (English, French, Spanish)
- File request/download system
- Vacation messaging system
- ProBoard BBS support path

### 2001 — Final Version
- OLMS 2001 (v2.00.1 beta 3) — last known release
- RemoteAccess 2.x target (RA2 build switch)
- Hudson + JAM dual message base

### 2026-07 — Clean-Room Recreation (OpenOLMS)
- The crew (verta1878) created a clean-room FPC recreation before source was available
- OpenOLMS deliverables: openolms-complete.zip, openolms-v10.zip, etc.
- Based on binary analysis and BBS protocol documentation
- This work is archived in attic/ as historical reference

### 2026-10-15 — Author Source Released
- Original author made contact with the crew
- Full source archive (_OLMS2K.ZIP, 142 files) provided
- 22 Pascal source files, 14,257 lines
- Includes original binaries, MAP files, precompiled TPUs
- Replaces the clean-room recreation on GitHub

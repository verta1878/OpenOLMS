==============================================================================
 OpenOLMS - INSTALL
==============================================================================

REQUIREMENTS
  - Free Pascal Compiler (FPC) 2.6.4 or 3.2.x
  - For DOS: go32v2 cross-compiler (ppcross386)
  - For Win32: i386-win32 cross-compiler or native FPC
  - For MOLMS: Free Vision (FV) units for target platform

QUICK BUILD (Linux)
  cd src
  fpc olms.pas              # builds the door
  fpc config.pas            # builds the config editor
  fpc molms.pas             # builds the MOLMS client (needs FV)
  fpc olmsmnt.pas           # builds maintenance tool

QUICK BUILD (DOS cross-compile)
  ppcross386 -Tgo32v2 olms.pas
  ppcross386 -Tgo32v2 config.pas

QUICK BUILD (Win32 cross-compile)
  ppcross386 -Twin32 molms.pas

INSTALL AS A BBS DOOR
  1. Copy OLMS.EXE and CONFIG.EXE to a door directory (e.g. C:\OLMS\)
  2. Run CONFIG.EXE to set up paths, archivers, areas
  3. In your BBS menu editor, add:
       Command: C:\OLMS\OLMS.EXE
       Parameters: (optional switches, see docs/RUNNING.md)

SPELL CHECK (optional)
  See docs/SPELL_SETUP.md for Hunspell library + dictionary setup.

MOLMS CLIENT
  1. Copy MOLMS.EXE to any directory
  2. Run MOLMS.EXE
  3. Add a BBS to the address book (BBS menu -> Add BBS)
  4. Use Auto Mail Run (Alt-M) for one-key mail cycle

 OpenOLMS - TODO / ROADMAP
==============================================================================

PLANNED
  - Wire MOLMS reply composer to full FV editor (multi-line, cursor movement)
  - Wire REP packing from MOLMS reply queue into uploadable .REP files
  - Search messages by keyword/sender/subject in the MOLMS reader
  - Interactive front-end: menu-driven UI when OLMS door runs for a caller
    (conference select, read/scan, pack, upload) matching classic OLMS screens
  - Local mode: run OLMS at the console as the sysop (no dropfile)
  - Read RemoteAccess CONFIG.RA to auto-fill system/sysop names and areas
  - File uploaded replies back INTO the message base (currently parsed only)
  - Wire mterm's ANSI/RIP viewer into the MOLMS message display

NICE TO HAVE
  - More archivers preconfigured (ARJ, LHA, ZIP variants)
  - Reader-compatibility testing against MultiMail / Blue Wave / etc
  - Internet / QWKnet gateway polish
  - Phonebook import/export
  - Threaded message view (tree display by RefNum)
  - Message tagging and batch operations
  - Offline file requesting through MOLMS

KNOWN LIMITATIONS
  - The graphical SDL config UI is for modern OSes (Windows/Linux/macOS) only;
    real DOS uses the text (CRT) config UI
  - MOLMS client requires FV (Free Vision) for the TUI; DOS door uses pure ANSI
  - Spell check requires Hunspell library + dictionary; silently disabled if
    not present (see docs/SPELL_SETUP.md)
  - Tested primarily via Linux build plus DOS smoke tests

Have a request or a bug? Open an issue at github.com/verta1878/OpenOLMS

# Releases

Prebuilt DOS binaries (go32v2), built from this source with Free Pascal.
Run them with the bundled `dos-runtime/CWSDPMI.EXE`.

  OLMS.EXE     the mail door
  CONFIG.EXE   the sysop config tool

The full ready-to-run DOS bundle (these + CWSDPMI + sample data) is attached to
the GitHub Release as `openolms-0.1-dos.zip`.
